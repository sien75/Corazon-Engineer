# how-to

> 本文件是中文镜像,以英文版 `README.md` 为准。

系统怎么构建、怎么操作。本文件是 `how-to/` 这棵树的契约 —— 动这里之前先读它。普通文件树,下面的布局就是它的契约。

## 目录结构

```
how-to/
├── README.md          # 本文件
├── deploy/[env]/      # 构建 / 打包 / 启动 / 部署,按环境
│   └── BOOK.md        # 该环境的操作手册
└── operation/         # 怎么连接 / 观测资源(数据库、缓存、日志、服务)
```

两个模块:

- **`deploy/`** —— 按环境的构建 / 打包 / 启动 / 部署;负责确保项目成功启动,不负责验证业务功能。
- **`operation/`** —— 连接并观测资源(数据库、缓存、日志、服务实例),含 telemetry:实时监控、历史日志查询,以及对底层资源的主动操作。

## 约定

- env 名 = `deploy/` 下的目录名。
- 结构化数据放 yaml;其余都是散文。
- 系统怎么测试放在 `development/testing/`,不在这里。
- 凭证不在这里配置。外部工具各自的凭证放在各自的 `~/.xxx` 位置。
