格式

<!doctype html>

<meta id="身份">

<script type="blueprint/sql">      建表，是前后端唯一协议
<script type="blueprint/flow">     on / steps / run / sql / emit / ai / with
<script type="blueprint/sh|js|…" id="步骤名">
                                   stdin 收 JSON，stdout 回 JSON

<body> 页面照常写，用 bp.emit / bp.watch / bp.on / bp.sql
