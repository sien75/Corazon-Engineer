工具作用mainsub

Skill

skill 不是工具：它是一个 SKILL.md 文件。pi 按目录约定自动发现，把名字和描述列进系统提示， agent 需要时用 read 读它。

项目级

<cwd>/.agents/skills/<slug>/SKILL.md

从 cwd 逐级向上到 git 根，每一级都看 .agents/skills。

用户级

~/.agents/skills/<slug>/SKILL.md

还有旧的 ~/.pi/agent/skills。两个角色都看得见，和项目无关。
