---
name: contract-drift
description: 核对契约文件、实现代码与 docs 三者是否还对得上
---

检查契约文件和实现是否还一致。

1. 读 `contracts/` 下每个契约的 request / response 字段。
2. 找到对应实现（通常在 `workspace/<atom>/`）和调用方，逐字段核对：字段名、必填与否、类型、枚举取值、错误码。
3. 同时核对 `docs/<atom>.md` 里的接口说明跟契约是否一致。
4. 输出一张漂移表，三列：契约 / 实现 / 文档。一致打 ✓，不一致写清差在哪。
5. 有漂移时问用户按哪边改，**不要自己动手**。

只读，不改任何文件——这一步只是把差异摆到台面上。
