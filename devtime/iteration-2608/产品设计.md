# 前端设计

## 形态
web / app / cli 多端,统一通过接口交互,不直接碰数据。
UI 风格:无样式 + 趣味动效(文字颤抖 / 倾斜 / 倒下 等)。

## 在三层架构中的位置
- 前端 ↔ AI:调 AI 接口(ask / plan / operate 等)
- 前端 ↔ 后端:直接调后端原子接口(schema 查询 / 运行时数据 / sse / 测试)
- AI ↔ 后端:AI 执行编排时调后端原子接口

## 视图

### 1. 主视图:可交互架构图
- 进系统第一眼看到的页面
- 基于 schema 绘制,只展示简单关系(atom 节点 + edge 连线),不堆信息
- 对应 schema 查询接口,数据一次性拉取

### 2. 详情面板(静态)
- 点击 atom / edge 展开
- atom 详情:全量信息(interfaces in/out、runtime、observability 等)
- edge 详情:from/to、channel/protocol、描述
- 数据复用 schema 查询结果,不单独发请求

### 3. 运行时面板(动态)
- 前提:已通过 scenario 连接到执行中的实例
- edge 详情里展示实际调用记录
- 全局 sse 订阅:edge 被触发时,架构图上对应 edge 播放动画,提示此处发生调用
- 可下钻到 log / trace / metric

### 4. 测试面板
- 系统级测试用例列表(测试会改 sql,不能单测 service)
- 查询用例 + 触发测试 + 查看结果

## schema 编辑
- 增删改不直接写 YAML,面向 AI 设计
- 前端给 AI 下指令 → AI 调后端原子 mutation 接口 → 结果回显到架构图
