# 主题菜单监听失而复得

## 需求

顶栏的 theme 按钮点了没反应。用户报障：「theme 这个按钮怎么不生效了」。

## 现状（实测）

- `workspace/web/index.html` 里 `#theme-toggle` / `#theme-menu` 的 markup 在，`style.css`
  里 `#theme-toggle` / `#theme-menu` 的样式（`.active`、`[hidden]`）也在。
- `workspace/web/app.js` 里只剩 `currentTheme()` / `applyTheme()` / `pushPageTheme()`：
  `syncThemeMenu()` 和 `themeMenuHide()` **没有定义**，三个监听器（toggle 点击、菜单项点击、
  点外部关闭）**没有绑定**。所以按钮渲染出来、点下去什么都不发生。
  `applyTheme()` 里那句 `syncThemeMenu()` 也没人触发到——真触发了就是 `ReferenceError`。
- 正在跑的那套（`serve-web` 端口 7500）服务的是
  `~/.engineer/apps/versions/engineer-v0.6.0-26-g9d4f406-darwin-arm64/web`，
  那份 `app.js` 同样只剩第 44 行一个孤立的 `syncThemeMenu()` 调用——线上这份也是坏的，
  不是本地工作区独有的问题。

## 根因

`git show 84d52d0 -- workspace/web/app.js`：提交「Give main a workspace of tools, one
project page, and session-delete」重写 app.js 时，主题菜单那一整块（两个 helper + 三个
监听器）作为一大段**纯删除**被扫掉了。同一段里被删的 composer 处理器（`aiPaste` /
`aiInputKeydown` / resize 等）后来在 `components/chat.js` 里有了新家，主题这块没人接盘，
于是 markup、样式、`applyTheme`/`pushPageTheme` 都活着，唯独没人绑事件。

## 方案

在 `workspace/web/app.js` 里、`pushPageTheme()` 之后补回这一块（形状与删除前一致）：

1. `syncThemeMenu()`：把当前主题对应的菜单项标成 `.active`。
2. `themeMenuHide()`：隐藏菜单、去掉 toggle 的 `.active`。
3. 三个监听器：toggle 点击开/关菜单（`stopPropagation`，避免被「点外部关闭」立刻关掉）、
   菜单项点击 `applyTheme()` + 收起、window 点击时菜单外点击收起。
4. 补一个 window `keydown`：Esc 关菜单，且 `stopPropagation()`——对话自己的 Esc
   （`components/chat.js` 里按 pane 绑定）不受影响。

不动 `currentTheme` / `applyTheme` / `pushPageTheme` 本身：切主题、存 localStorage、
往 iframe 页面推 `data-theme` 的逻辑一直是对的，缺的只是入口。

## 验收

在 dev 栈（`how-to/deploy/dev/launch.sh`，8500 一套，`--assets workspace/web`）上用浏览器实测：

- 点 `#theme-toggle`：菜单 `hidden=false`、toggle 带 `.active`。
- 点 dark / solarized / light：`html[data-theme]` 与 `localStorage["engineer.theme"]` 跟着变，
  `body` 背景色随之变化（`#fff` → `#141416` → `#fdf6e3`），菜单自动收起。
- 刷新页面：主题保持（solarized 仍为 solarized）。
- 从 launcher 打开 Pure Chat（真 iframe 页面）：外壳切 dark 后，iframe 里
  `data-theme=dark`、背景 `rgb(28,28,32)`——`pushPageTheme()` 那条路通。

结果：全部通过。记录见 `POST /log/mutation`（`kind: test`，case `theme-toggle-restore`）。

## 遗留

改动只在工作区 `workspace/web/app.js`，当前 7500 那套服务的是已安装版本的静态资源，
要生效得按 `how-to/deploy/prod/BOOK.md` 重新打包安装并重启；这次没做。
