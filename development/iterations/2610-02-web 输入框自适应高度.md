# web 输入框随内容自适应高度

## 需求

web 的 AI 输入框（`#ai-input-field`）在内容换行时随之变高：

- 软换行（长行按宽度折行）与显式换行都计入；
- 行数口径为**渲染后的可视行数**；
- 最小 2 行（保持现状），最大 10 行；
- 超过 10 行后不再变高，改为输入框**内部滚动**。

## 现状

- `workspace/web/index.html:55` 为 `<textarea id="ai-input-field" rows="2" …>`；
- `workspace/web/style.css:916` `#ai-input-field` 高度由 `rows=2` 决定，`resize: none`，无上限与滚动；
- `#ai-input` 是 flex 行（`style.css:713`），默认 `align-items: stretch`，send / stop 按钮随行高拉伸；
- `workspace/web/app.js` 多处直接给 `.value` 赋值，**程序化变更不触发 `input` 事件**，只挂 `input` 监听会漏掉这些路径。

## 方案

### 高度测量（app.js）

新增 `aiResizeInput()`：

1. `getComputedStyle` 取 `line-height` / `font-size`（`line-height: normal` 时回退 `font-size × 1.4`）、上下 padding 与 border；
2. `maxHeight = lineHeight × 10 + padding + border`；
3. `style.height = "auto"` 复位后读 `scrollHeight`，`contentHeight = scrollHeight + border`；
4. `height = min(contentHeight, maxHeight)`；`overflowY = contentHeight > maxHeight ? "auto" : "hidden"`。

要点：

- 全局 `box-sizing: border-box`（`style.css:2`），`scrollHeight` 只含 content + padding、**不含 border**；不补 border 会误判为溢出，非溢出状态下也冒出滚动条。
- `height:auto` 时 textarea 退回 `rows=2` 的固有高度，故内容 ≤ 2 行时天然保持 2 行最小高度，无需单独处理。
- 上限由 CSS 计算得出（`line-height` 为 1.4、字号 13px ⇒ 约 196px），改字号 / 行高 / 行数上限时无需同步改数字常量。

### 触发时机

- `input` 事件（键入、文本粘贴）——与现有 `aiSyncCommandDrawer` 并存；
- 程序化改 `.value` 的 5 处：`aiInsertImageToken`、发送后清空、命令抽屉选择后清空、Tab 补全命令、Backspace 删除 `[image]` token；
- 窗口 `resize`（宽度变化 ⇒ 软换行行数变化）；
- 打开 AI 面板时（隐藏状态下 `scrollHeight` 不可靠，需在 `hidden = false` 之后重算）。

### 布局

`#ai-input` 由默认 `align-items: stretch` 改为 `align-items: flex-end`：输入框长到 10 行时，send / stop 按钮沉底，不再被拉成 10 行高。（**待确认**，是本次唯一会影响 2 行默认观感的改动。）

### 范围外

- 不把最大行数做成可配置项；
- 不改 AI 面板宽度、消息区高度；
- 不改后端、`contracts/`、`atoms/` `edges/`（纯前端内部行为，接口契约不变）。

## 验收

- 空 / 单行内容：输入框 2 行高（与现状一致）；
- 长行触发软换行：高度随可视行数增长；
- `Shift+Enter` 显式换行：同样增长；
- 达到 10 行：高度停在 10 行，继续输入出现内部滚动条；
- 删除内容 / 发送清空 / 删除图片 token：高度回落；
- 窗口宽度变化：折行数变化后高度重算；
- 面板关闭再打开：高度正确。

## 影响面

仅 `workspace/web/app.js` 与 `workspace/web/style.css`（若采纳 `flex-end`）。无接口、无 schema 变更。
