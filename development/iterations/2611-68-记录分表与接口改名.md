# 2611-68 记录分表与 log 接口改名

## 目标

1. 去掉 `current` 表：工作区状态（哪些会话开着、哪个是 main）变成 `sessions` 自己的列。
2. 记录按用途分表：conversation 留在 `records`，test 进 `tests`，telemetry 进 `telemetries`。存储设计不变 —— 每张表仍是现在的列（`id / created_at / kind / env / atom / session_id / summary / payload`），payload 依旧是 yaml 文本。已有数据不迁移（旧 test / telemetry 行留在 `records`）。
3. log 的 provides 统一命名：只允许 `log-session*`、`log-project*`、`log-test*`、`log-telemetry*` 三个前缀，外加 `log-search`、`log-stream` 两个特例。

## 数据库

`sessions` 增三列（旧库就地 ALTER）：

| 列 | 含义 |
|---|---|
| `open_index INTEGER NOT NULL DEFAULT -1` | 在 tab 栏里的位置；-1 = 没打开 |
| `is_main INTEGER NOT NULL DEFAULT 0` | 1 = 当前 main（唯一，partial unique index） |
| `touched_at TEXT NOT NULL DEFAULT ''` | 最后一次参与工作区变更的时间，`current/updatedAt` 由它取 max 得来 |

索引：`idx_session_open`（partial，`open_index >= 0` 唯一）、`idx_session_main`（partial，`is_main = 1` 唯一）。

迁移：若存在 `current` 表，读出 `open_sessions` 与 `main_session` 写进 `sessions`，然后 `DROP TABLE current`。`open_tabs`（更老的一版）不再兼容：那批库直接丢掉 tab 顺序，会话本身不受影响。

记录表：`records`（conversation，含历史 test / telemetry 行）、`tests`、`telemetries`，三张同构。

## 接口

| 旧 | 新 |
|---|---|
| `/log/list` | `/log/session/list`（`log-session-list`） |
| `/log/delete` | `/log/session/delete`（`log-session-delete`） |
| `/log/session/detail` | 不变，id 由 `log-session-kind` 改名 `log-session-detail` |
| `/log/current/get` | `/log/session/current/get`（`log-session-current-get`） |
| `/log/current/put` | `/log/session/current/put`（`log-session-current-put`） |
| `/log/mutation`（kind=conversation） | `/log/session/record/add`（`log-session-record-add`） |
| `/log/mutation`（kind=test） | `/log/test/add` |
| `/log/mutation`（kind=telemetry） | `/log/telemetry/add` |
| `/log/query` | `/log/test/query`、`/log/telemetry/query`（body 不再有 `kind`） |
| `/log/query-detail` | `/log/test/detail`、`/log/telemetry/detail` |

不变：`log-session-{messages,upsert,on,off}`、`log-project-*`、`log-search`、`log-stream`。

读接口跨表：`query` / `search` / `detail` 一律覆盖 `records` + 对应分表（旧行没迁），写入按 kind 路由到自己的表。

## 影响面

- log：`store/workspace.go`（sessions 列、current 派生、drop 表）、`store/store.go`（分表与路由）、`server/server.go`（路由与 handler）。
- ai：`recorder.ts`（写 conversation 的新端点）、`registry.ts`（session/delete）、`workspace.ts`（list / current 路径）。
- web：`app.js`（list / current 路径）。
- structure：contracts 改名与新增、`atoms/log.yaml` `atoms/ai.yaml` `atoms/web.yaml`、`edges/ai-to-log.yaml` `edges/web-to-log.yaml`、`docs/log.md`。
- agents 规范 4 份（写记录的接口名）+ `development/testing` 里引用旧路径的用例。

## 不做

- 不改 payload：`conversation` 仍是 `{seq, role, content, raw?}` 的 yaml。
- 不迁移旧数据，不写数据修复脚本。
- `current` 的语义不变（开着的会话 + main），只是换存储位置。
