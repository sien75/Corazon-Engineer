# 2611-69 标题生成兼容与临时标题

## 现象

无蓝图的纯对话：tab 先是 `new tab`，发第一条后变 `…`，第一轮回答结束后又等好几秒才变成 `chat`，之后永远是 `chat`。

## 原因（已核实）

1. 会话模型换成 `zenmux-claude/anthropic/claude-sonnet-5.5` 后，标题生成每次失败。标题请求不传 `reasoning`，pi 就发 `thinking: {type:"disabled"}`（`pi-ai/dist/api/anthropic-messages.js:809`），Sonnet 5.5 返回 400（要求改发 `between_tools`）。3 次尝试 + 间隔 1s，所以要几秒才结束。
2. 失败后标题没变，服务端仍发 `session_title`，内容是初始名 `chat`（`registry.ts:807`），前端把 tab 改成 `chat`。
3. 实测：DeepSeek 官方、ZenMux Haiku 接受 `disabled`；Sonnet 5.5 拒绝；不带 `thinking` 时 Sonnet 5.5 约 2.3–2.9s 出标题（会思考约 100 token），`between_tools` 约 2s、输出约 10 token。

## 范围

做：
1. 标题请求对"拒绝 `thinking: disabled`"的模型自适应。
2. 失败时不再用 `chat` 覆盖 tab 名。
3. 无蓝图对话：第一条消息发出后，tab 先用用户问题的前 N 个字做临时标题，AI 总结出来后再替换。

不做：
- 不动 pi 的配置文件（`~/.pi/agent/models.json`）。
- 不新增"标题专用模型"配置。
- 不改对话请求的思考参数（只有标题请求经过改写）。
- 不处理 `ai.log` 里的 "tab character" 记录写入失败（另一个问题，单独处理）。

## 设计

### 1. 标题请求的思考参数自适应

只改标题请求（`registry.ts` 的 `generateTitle`），做法是 `completeSimple` 的选项里加 `onPayload` 钩子（`pi-ai/types.d.ts:73`，请求发出前可改请求体）。

- 默认不改，保持 `thinking: disabled`：DeepSeek 官方等照旧，不会回到默认思考。
- 一次尝试失败且错误是 400、报错文本含 `thinking` 时，把该模型记为"需改写"，下一次尝试用钩子把 `thinking: {type:"disabled"}` 换成 `{type:"between_tools"}`。
- "需改写"的结论按 `provider/model-id` 记录：内存里一份，同时落盘到 `<data home>/model-quirks.json`（data home 即 ai 的 `--home`，如 `~/.engineer/data/`）。ai 启动时读入，之后同一模型直接用改写后的请求，不再多一次失败往返。
- 其他 400（密钥错误等）不记；改写后仍失败的，不再继续改写，走原有的"保留旧名"。

`model-quirks.json` 形状：

```json
{ "zenmux-claude/anthropic/claude-sonnet-5.5": { "thinkingDisabledRejected": true } }
```

落盘的取舍：省下的只是每次重启后一次约 0.3s 的失败请求；代价是厂商以后修好了，文件里仍是旧结论。因此读到该标记时，改写后的请求若同样 400，则清除该条目，让它重新探测。

### 2. 失败不覆盖 tab 名

标题没变（失败或与现名相同）时，`session_title` 仍要发（它同时是流的收尾信号），但 `title` 字段为空。前端 `engineer-title` 监听本来就忽略空标题（`chat.js:965`、`app.js` 里 `if (!renamed …) return`），tab 保留临时标题。

### 3. 临时标题

- 触发：无蓝图（`blueprint === ""`）的会话，用户发出第一条消息、会话刚被创建时。
- 内容：该消息去掉首尾空白、折叠空白后取前 N 个字符（中文按字，英文按字符），N 默认 10，超出不加省略号。
- 位置：前端。`engineer-session` 事件的 `detail` 带上第一条消息文本，`adoptSession` 在 `tab.name` 为 `new tab` / `…` 时用它作为 tab 名。不经过服务端，因此立即可见。
- 有蓝图的会话不变：仍是页面 `<title>`，第一轮后被 AI 标题替换。
- 之后 AI 标题到了，走原有 `engineer-title` 替换。

## 待确认

1. N：默认 10，与 AI 标题的中文上限（`MAX_CJK = 10`）一致。
2. 落盘还是只记内存：已定落盘到 `model-quirks.json`。
3. 改写值用 `between_tools`（更快、约 10 token）还是直接删掉 `thinking`（更通用，约 2.5s）：倾向 `between_tools`，因为已被该报错明确指定为替代值。

## 验证

- 单元：钩子在 `disabled` + 400 之后才改写；其他 400 不记；`model-quirks.json` 读写与清除。
- E2E（无代理）：模型设为 Sonnet 5.5，无蓝图新建对话，发第一条消息 → tab 立即显示前 N 个字 → 数秒内变为 AI 标题；模型设为 `deepseek-flash` 时行为不变；标题请求失败时 tab 保持临时标题而不是 `chat`。
