# chat 滚动区占满整宽

## 需求

chat 页的对话内容仍然只在中间 1000px 的列里展示，但**滚动范围要占满整屏**：
鼠标停在列的左侧 / 右侧空白处，滚轮也要能滚整个对话。

## 现状

- skill-mode 下 `#ai` 是竖向 flex（`#ai.skill-mode { flex: 1 }`），里面两项：
  `#ai-messages`（`flex: 1` + `overflow-y: auto`）在上，`#ai-input` 在下。
- `#ai > * { width: 100%; max-width: 1000px; margin-inline: auto }`（`style.css:584`）
  把两者都限成 1000px 并居中，所以 **`#ai-messages` 一个盒子既是滚动容器又是那
  1000px 的列**：滚轮只有落在列这个盒子里才滚。
- 列的左右两侧是 `#ai` 的空白，不属于任何滚动容器 —— 滚轮无效（用户报的问题）。
- 贴底判定 `aiAtBottom()` / `aiScrollToBottom()`（`app.js:618` / `632`）直接读写
  `aiMessagesEl` 的 `scrollTop` / `scrollHeight` / `clientHeight`。

## 方案

把「滚动容器」与「内容列」拆成两层。

### 1. DOM 多包一层（index.html）

```html
<aside id="ai" hidden>
  <div id="ai-scroll"><div id="ai-messages"></div></div>
  <div id="ai-input">…</div>
</aside>
```

`#ai-messages` 仍是消息宿主，位置不变（仍在 `#ai` 里、仍是 `#ai-input` 的前一个兄弟），
所以 `#ai-messages > .ai-chip-row` 这类选择器和所有 `appendChild` / `innerHTML` 都不用改。

### 2. CSS（style.css）

- `#ai-scroll { flex: 1; min-height: 0; width: 100%; overflow-y: auto;
  scrollbar-gutter: stable both-edges; }` —— 滚动容器占满整宽、占满 composer 以上的整高。
- 把 `#ai > *` 的点名规则换成 `#ai-messages, #ai-input { width: 100%;
  max-width: 1000px; margin-inline: auto; }` —— 列的定义不变，只是不再包含滚动容器。
- `#ai-messages` 去掉 `flex: 1` / `overflow-y` / `scrollbar-gutter`；`padding-right`
  从 18px 回到对称的 12px（那 6px 原来是给它自己盒子里的滚动条让位的，现在滚动条
  在 `#ai-scroll` 上）。
- `both-edges`：classic scrollbar 平台下 `scrollbar-gutter: stable` 只留右侧槽位，
  列心会比 composer 心偏左半条滚动条宽；两侧等留就重合（overlay 滚动条平台上两者
  无差别，但留一侧始终更稳）。

### 3. JS（app.js）

- 新增 `const aiScrollEl = document.getElementById("ai-scroll")`。
- `aiAtBottom()` / `aiScrollToBottom()` 改读写 `aiScrollEl`；`aiMessagesEl` 仍然只当
  内容宿主。消息区没有 scroll 事件监听（贴底是在追加内容时现算的），所以只有这两处。

### 范围外

- 不改消息结构、气泡宽度、composer 行为、贴底阈值。
- 滚轮落在 composer 那一行（底部输入区）不滚对话 —— 它不是对话区。
- 不自定义滚动条样式（overlay / classic 交给平台）。
- 不改 `contracts/` `atoms/` `edges/`，不改 ai / log / static 服务。

## 验收

- `#ai-scroll` 的宽度 = `#ai` 的内容宽（左右各贴到 0~1px），纵向从消息区顶部一直占
  到 composer 上沿。
- `#ai-messages` 仍是 ≤1000px、在 `#ai` 里居中的列（与 composer 同轴）。
- 鼠标停在列左侧空白处滚轮 → 对话滚动；停在列右侧空白处滚轮 → 同样滚动。
- 鼠标停在列内滚动 → 行为不变（回归）。
- 贴底逻辑不变：贴底时追加消息仍自动滚到底。
- 窗口窄于 1000px 时列退化为整宽（既有行为，`max-width` 不变）。
