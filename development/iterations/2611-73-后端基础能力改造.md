# 2611-73 后端基础能力改造

> 状态:方案,未实现。原则:**先去,再增**——本轮只做减法,不管功能是否完善,新界面与新能力后续另起迭代。

## 目标

系统收缩到最小:一个 main 对话 + 主题切换。

- **ai**:就是一问一答,一个 `sessionId` 区分一个会话;new / ask / stream / stop / resume / delete。不认识 kind、blueprint、project、tab / index,没有 main / sub 之分。**ai 的工具全部保留**(`ask_user`、`model`、`usage`、`compact`、`web_search`、`image` 等)。
- **storage(log)**:只存会话与消息记录,不再有项目、工作区、测试 / 观测记录、搜索、订阅流。
- **前端(web)**:只有一个 main 对话和主题切换,别的全部去掉。

## 环境约束

涉及 sqlite 的改动**只在 dev**:数据目录 `<checkout>/.engineer/home`(`how-to/deploy/dev/launch.sh`)。**不碰生产库**(`~/.engineer/data/engineer.db`、`~/.engineer/engineer.db`)。新结构与旧库不兼容,不迁移、不兼容旧会话,dev 库不兼容时直接重建。

## ai 改动

### `/ai/new`

```yaml
cwd: string       # 工作目录(绝对路径),调用方解析好
system?: string   # 追加到系统提示词的整段文本,调用方拼好
title?: string    # 初始标题,缺省 "chat"
chat? / image?    # 不变
```

返回 `sessionId / chat / image`。去掉 `projectId / blueprint / kind / model(别名)`。

### 去掉

- `blueprint.ts` 整个删除(README 读取、`<title>` 取标题、slug 校验、`BlueprintError`)。
- `registry.ts`:`projectDir`(调 `/log/project/get`)、`blueprintTail`、按 kind 选 spec、`kind==="sub"` 分支全部去掉;`new/resume` 只认 `cwd + system`。
- **接口调用相关全删**:不再向 agent 注入接口文档(`docsLine`)、运行时端点(`runtimeEndpoints`)、reference 目录说明;`--agents` / `--docs` 启动参数随之去掉;`gen-docs` 与 `structure/docs/` 的接口文档生成不再被 ai 使用。agent 要什么说明,由调用方放进 `system`。工具本身不动。
- `models-config.ts`:`models.yaml` 不再分 main / sub,只剩一份 `chat` / `image` 默认。
- `title.ts`:去掉 blueprint 初始标题分支,标题只来自 `title` 入参与首轮自动总结。
- ai 访问 storage 只剩:`session/record/add`、`session/messages`、`session/upsert`、`session/detail`、`session/delete`。
- `resume` 只靠会话行里的 `cwd / system` 重建。

## storage(log)改动

### sqlite:只剩 2 张表(dev 重建)

- 删表:`projects`、`tests`、`telemetries`;`recordTables` 只剩 `records`。
- `sessions` 表:`session_id`(主键)、`cwd`、`system`、`title`、`model`、`image_model`、`touched_at`、`created_at`。去掉 `kind`、`blueprint`、`project_id`、`open_index`、`is_main` 及两个唯一索引。

### 接口:`/log/*` 24 个剩 6 个

| 保留 | 说明 |
|---|---|
| `session/upsert` | 存会话行,字段换成新 8 列 |
| `session/detail` | 读一个会话 |
| `session/list` | 按最近活跃列会话(去掉 kind / blueprint / project 字段与过滤;main 对话靠它找回最近一个) |
| `session/messages` | 取消息 |
| `session/record/add` | 追加消息(ai 写) |
| `session/delete` | 删会话及记录 |

删除 18 个:
- project 5:`add` `get` `list` `remove` `visible`
- 工作区 5:`session/current/get|put`、`session/on|off`、`workspace/stream`
- test 3:`add` `detail` `query`;telemetry 3:`add` `detail` `query`
- `search`、`stream`(前端只剩一个 main 对话,无人使用)

### `/static/*` 保留,入参改 `path`

`query` / `query-detail` / `stream` 三个接口保留,入参 `projectId` 改为 `path`(项目文件夹绝对路径);相对路径 400,目录不存在 404;`safePath` 越界检查不变,以 `path` 为根。代码:`static.go` 的 `projectDir` / `root` 改为直接校验 `path`,不再碰 store。

## 实现记录(与方案的差异)

- **`sessions` 7 列**,不是 8:`touched_at` 一并去掉(它只为工作区服务,排序改用消息时间)。
- **`/static/stream` 改为每个连接盯自己的 `path`**:没有项目看板,服务端没有"该盯哪些目录"的答案,所以订阅时给目录,该连接每秒轮询那个目录并在变化时推事件;不存在的目录 404。
- **web `serve-web` 新增 `--cwd`**:一方对话总得有工作目录,由启动方传(checkout 根),页面从 `/config.js` 拿到并交给 `/ai/new`。
- **ai 启动参数只剩 `--bind/--port/--home/--storage`**:`--agents`/`--docs` 删除;ai 不再注入 spec、reference、runtime endpoints,agent 要什么由调用方放进 `system`。
- **`models.yaml` 兼容旧形状**:平铺的 `chat`/`image` 优先,缺失时读旧的 `main.chat`/`main.image`,所以已有数据家不会突然掉到内置默认。
- **顺手修掉一个既有类型错误**:`appendSystemPromptOverride` 的回调是 `(base: string[]) => string[]`,原来把 `base` 当成一个元素塞进数组(嵌套数组,拼出来是逗号连接);改成 `...base`。
- **测试**:删 18 个用例(blueprint / 工作区 / tab / 路由 / launcher / recents / 蓝图页伺服等);新增 `case-core-web-single-chat`(一方对话 + 主题切换 + 旧路径回落 + 刷新复用同一会话);其余 12 个用例按新参数改写(`cwd`/`path`,去掉 kind/blueprint/projectId)。
- **已验证**(dev,`:8500/:8501/:8502`):新表结构只有 `records`/`sessions`;`ai/new` → 会话行 7 字段;`ask`+`stream` 全程 `agent_start…session_title…agent_settled`;首轮标题写回会话行(`title` 参数作起点);`log/session/{detail,list,messages,delete}`;`static/{query,query-detail,stream}` 按 `path` 取(含 400/404 分支);`gen-docs` 无漂移;`case-core-web-single-chat` 全绿。
